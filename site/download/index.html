The latest release, signed on every platform it ships for. Release notes.

macOS

macOS 14 or later · Apple silicon and Intel
  • A universal disk image, signed, notarized and stapled, so it opens without a Gatekeeper argument.
  • Checks for an update on launch, and never installs one behind your back.
Download .dmg

Windows

Windows 10 or 11 · x64
  • An Authenticode-signed installer from Sassy Dog Enterprises LLC.
  • No update channel yet: the app says so plainly, and you install the next release over this one.
  • Windows 10 needs the WebView2 runtime; Windows 11 already has it.
Download installer

Linux

The agent, not the cockpit
  • There is no cockpit build for Linux.
  • A Linux box shows up in your cockpit by running the agent: a small signed binary that serves its metrics and containers to the cockpits you pair with it.
Install the agent

The agent

The agent is how another machine appears in your cockpit: a Linux server, a second Mac, the box under your desk. It ships on a release train of its own (agent-vYYYY.M.N), found through a signed feed rather than the cockpit's latest release above, and its installer checks every signature before anything runs. Set one up, or see the agent reference.

Build it yourself

Solador is Apache-2.0 and the whole of it is on GitHub: a Rust workspace and a Tauri v2 app. Build from source with a Rust toolchain and ./dev.
